# Entradas manuales

Estas son las entradas que puede utilizar el usuario para interactuar con el modelo de datos

- Crear un usuario
- Crear una canción
- Agregar acordes, letra, tareas, tabs y demos a una canción
- Cambiar estado de una canción
- Agregar acordes sobre la letra (incluyendo espacios vacíos)
- Editar/borrar letra, acordes, tareas, tabs, comentarios de demos
- Agregar comentarios a una demo
- Cambiar título de una canción
- Cambiar tonalidad de una canción
- Crear una banda
- Crear/borrar invitación a canción/banda
- Guardar cambios a una canción
- Cambiar nombre de usuario (debe seguir siendo único)

> Revisión (2026-10-18, aprobada) — entradas agregadas:
> - Cambiar email y contraseña (siempre con la contraseña actual; cambiar la contraseña cierra las demás sesiones).
> - Ver y cerrar sesiones propias (dispositivos).
> - Usar un enlace de invitación para unirse a una canción o banda.
> - Quitar a un integrante de una canción o banda, cambiar su rol (canción) y abandonar una canción o banda.
> - Transferir la propiedad de una banda a un miembro.
> - Mover una canción personal a una banda.
