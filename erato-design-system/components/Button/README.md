# Button

La acción de una vista; `primary` (ámbar, con destello en hover) una sola vez por pantalla.

- Props: `variant` `"primary" | "quiet" | "ghost" | "danger"` (por defecto `quiet`), `size` `"md" | "sm"`, `icon` (nombre de `Erato.Icon`), `children` y cualquier atributo de `<button>`.
- Verbo primero, mayúscula inicial: «Nueva composición», «Escuchar demo».
- `ghost` para cancelar o acciones secundarias dentro de un panel; `danger` (wine) solo para borrar, y pide confirmación.
