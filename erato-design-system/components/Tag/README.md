# Tag

Chip mono en minúscula para estado y metadatos de una composición o demo.

- Props: `tone` `"neutral" | "amber" | "ember" | "wine" | "moss"`, `dot` (punto de color delante), `children`.
- `amber` = en progreso, `moss` = lista, `wine` = comentarios o alertas, `ember` = datos musicales (tonalidad, bpm). El texto siempre dice el estado; el color no va solo.
